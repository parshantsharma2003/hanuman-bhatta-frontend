# Brick Manufacturing Website Assets

Place your images and static files here:

- `images/` - Product photos, hero images, process photos
- `icons/` - Custom icons or logos
- `favicon.ico` - Website favicon

## Recommended Images

1. **hero-bg.jpg** - High-quality brick manufacturing scene
2. **brick-texture.jpg** - Close-up brick texture for backgrounds
3. **process-molding.jpg** - Molding process photo
4. **process-drying.jpg** - Drying process photo
5. **process-firing.jpg** - Firing/kiln process photo
6. **product-first-class.jpg** - First class brick photo
7. **product-second-class.jpg** - Second class brick photo
8. **product-brick-bats.jpg** - Brick bats photo
9. **logo.png** - Company logo

## Image Guidelines

- Use WebP format for better performance
- Optimize images before uploading
- Recommended hero image size: 1920x1080px
- Product images: 800x800px
- Process images: 1200x800px
